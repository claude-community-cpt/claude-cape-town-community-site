# Security

This repository holds the public website for Claude Community Cape Town
(https://claudecapetown.com). It is a static site with no server and no
database, and it stores no secrets.

## Reporting a problem

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/claude-community-cpt/claude-cape-town-community-site/security/advisories/new),
not in a public issue. We are volunteers and aim to reply within a week.

Useful things to include: the page or file affected, what you expected, what
happened instead, and steps to reproduce it.

## What must never be committed

- API keys, tokens or passwords of any kind. The forms post to public
  endpoints and need none.
- Personal contact details (email addresses, phone numbers) of hosts,
  speakers, venues or attendees.
- Attendee lists or exports from Luma.
- Programme material shared privately with ambassadors.
