Claude Community × stub. Alexander Oloo, CTO and co-founder of stub, explains what an agent actually is, builds one live, then helps you build your own with Claude Code. Every participant gets Anthropic API credits.

Bring a laptop with Claude Code installed, access to the Claude Console to load your credits, a charger, and one repetitive task you'd like to automate. No prior agent experience needed.

Doors 18:00, then setup, kickoff and demo, build time, show and tell, and networking until 21:00.
